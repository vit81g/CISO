# T1036 Masquerading — папка `pics`

В этой папке собраны скриншоты, иллюстрирующие все ключевые шаги расследования инцидента.

## Файлы

- **01_SIEM.jpg** — исходный алерт в SIEM KUMA по технике Masquerading.
- **02_SIEM.jpg** — детализация события, инициатор процесса, хост и IP‑адрес.
- **03_PS.jpg** — подключение к удалённому хосту по `\\host_name\c$`.
- **04_PS.jpg** — просмотр содержимого `Program Files (x86)` с параметром `-Force`.
- **05_PS.jpg** — вывод скрытых каталогов, в том числе `csrss`.
- **06_PS.jpg** — дополнительные команды PowerShell при анализе структуры каталогов.
- **07_Virus_total.jpg** — результат проверки хэша файла на VirusTotal (классификация Grayware).
- **08_PS.jpg** — вывод `Get-AuthenticodeSignature` по подозрительному файлу.
- **09_PS.jpg** — информация о сертификате `SignerCertificate` в виде `Format-List *`.

## Использование

- Скриншоты применяются как *evidence* при внутреннем расследовании и внешних аудитах.
- При добавлении новых кейсов Masquerading рекомендуется использовать схожее именование: `NN_Контекст.jpg`.
