# T1036 Masquerading — папка `docs`

В этой папке находятся текстовые материалы, связанные с разбором инцидента подмены системного процесса `csrss.exe` (MITRE ATT&CK T1036 Masquerading).

## Состав

- **T1036_Masquerading(csrss).docx**  
  Подробный отчёт о расследовании инцидента:
  - описание алерта SIEM KUMA;
  - пошаговая проверка системы через PowerShell;
  - результаты анализа хэша в VirusTotal;
  - анализ цифровой подписи и сертификата;
  - итоговые выводы о признаках Masquerading.

## Рекомендации по использованию

- Для формальной отчётности (отчёты ИБ, согласование с руководством) используйте `.docx`.
- Для быстрой навигации и ссылок при расследовании аналогичных кейсов используйте корневой `README.md`.
