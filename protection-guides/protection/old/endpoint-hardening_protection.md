# Endpoint Hardening

## 🎯 Цель
Снижение риска компрометации конечных точек (рабочих станций и серверов).

## 🔹 Меры защиты
- Отключить LLMNR и NBT-NS через GPO.
- Отключить WPAD.
- Включить антивирус/EDR на всех хостах.
- Регулярно устанавливать обновления ОС и ПО.
- Отключить SMBv1.
- Ограничить список локальных администраторов.
- Запретить автозапуск внешних носителей.

## 📊 Мониторинг
- Event ID 4624, 4625 — входы на хост.
- Логи антивируса и EDR.
