# Network Segmentation

## 🎯 Цель
Изоляция сегментов сети для снижения возможности lateral movement.

## 🔹 Меры защиты
- Разделить сеть на VLAN по ролям (пользователи, серверы, DC, админы).
- Запретить прямой доступ между сегментами, кроме необходимых сервисов.
- Применить egress ACL (запрет SMB/LDAP наружу клиентских VLAN).
- Изолировать админские рабочие места (PAW).
- Ограничить доступ к DC только с админских VLAN.

## 📊 Мониторинг
- Логи межсетевых экранов и маршрутизаторов.
- Попытки доступа к запрещённым портам между сегментами.
