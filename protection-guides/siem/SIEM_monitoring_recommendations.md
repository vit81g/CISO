# SIEM Monitoring Recommendations (Updated for 2025 Attack Techniques)

Данный документ содержит рекомендации по настройке мониторинга и корреляции событий для SOC в связи с новыми техниками атак на Active Directory и гибридные среды (2025).

---

## 1. BadSuccessor (Abusing dMSA)
### Логи и события
- Event ID 4662 — доступ к объектам AD с `ReadProperty` на dMSA.
- Event ID 4742 — изменение учётной записи компьютера.
### Корреляции
- Доступ к атрибуту `msDS-ManagedPassword` → вход сервисного аккаунта с нового хоста.
### Рекомендации
- Настроить оповещения при чтении чувствительных атрибутов dMSA.
- Сравнивать список хостов, откуда логинился сервисный аккаунт.

---

## 2. Golden dMSA Attack
### Логи и события
- Event ID 4662 — чтение `ManagedPasswordId`.
- Необычные подключения сервисных аккаунтов.
### Корреляции
- Чтение `ManagedPasswordId` → вход в критический сервис от нетипичного хоста.
### Рекомендации
- Включить аудит чтения `ManagedPasswordId`.
- Настроить оповещение на TGT/TGS запросы от gMSA с нетипичных систем.

---

## 3. AD Trusts Attack Paths
### Логи и события
- Event ID 4769 — Kerberos TGS requests междоменного характера.
- Event ID 4765/4766 — изменение SIDHistory.
- Event ID 4624 — вход trust-аккаунта.
### Корреляции
- Изменение SIDHistory → междоменный доступ с новым SID.
- Kerberos запросы между доменами без активности пользователя.
### Рекомендации
- Мониторить изменения trust-объектов.
- Настроить оповещение на междоменные TGS без интерактивного входа.

---

## 4. Hybrid AD Authentication Bypass
### Логи и события
- Логи ADSync DB доступа (SQL Server).
- Аномальные входы в Entra ID.
### Корреляции
- Доступ к ADSync DB → вход в облако без входа в локальный AD.
### Рекомендации
- Логировать доступ к ADSync DB.
- Настроить корреляцию между облачными входами и локальной аутентификацией.

---

## 5. LLMNR Poisoning Updated
### Логи и события
- Event ID 4624 Type 3 — вход SMB/LDAP от имени пользователя на атакующий хост.
- DNS-запросы к несуществующим именам.
### Корреляции
- DNS-запрос → вход по NTLM на неизвестный IP.
### Рекомендации
- Логировать и анализировать DNS-запросы с NXDOMAIN.
- Отслеживать входы по NTLM на неавторизованные хосты.

---

## 6. SMB Relay Updated
### Логи и события
- Event ID 4624 Type 3 — вход SMB от пользователя на нетипичный хост.
- Логи SMB без SMB signing.
### Корреляции
- NTLM вход без SMB signing → команды на SMB-хосте.
### Рекомендации
- Настроить оповещение на SMB-сессии без SMB signing.
- Сопоставлять входы и выполнение команд через SMB.

---

## 7. IPv6 Relay (MITM6)
### Логи и события
- Логи RA/DHCPv6 Guard (если включены).
- Event ID 4624/4769 с IPv6-адресов.
### Корреляции
- IPv6 конфигурация → NTLM вход на критический сервис.
### Рекомендации
- Логировать появление IPv6-адресов у критических хостов.
- Коррелировать с NTLM входами.

---

## 8. Pass-the-Hash
### Логи и события
- Event ID 4624 Type 3, 9.
- NTLM входы без ввода пароля (нет события 4776).
### Корреляции
- NTLM вход без события Kerberos/MFA → доступ к админским ресурсам.
### Рекомендации
- Логировать NTLM входы и сопоставлять с событиями Kerberos/MFA.
- Настроить оповещение на входы админов без интерактивной аутентификации.

---

## 9. Kerberoasting Updated
### Логи и события
- Event ID 4769 — выдача TGS сервисному аккаунту.
### Корреляции
- Массовые запросы TGS → попытка брутфорса.
### Рекомендации
- Настроить лимиты на выдачу TGS одному клиенту за короткое время.
- Оповещать при запросах TGS от нетипичных хостов.

---

## Общие рекомендации
- Включить аудит всех чувствительных изменений в AD.
- Разделить правила по категориям: **Authentication**, **Directory Changes**, **Network Traffic**.
- Использовать визуализацию цепочек атак в SIEM (MITRE ATT&CK view).
- Настроить пороговые значения для корреляций (например, более 5 TGS за 10 мин).
