# Рекомендации для SIEM по мониторингу атак NTLM Relay и связанных техник

## 1. Ключевые Event ID на Windows DC и серверах
- **4776** — NTLM authentication to DC.
- **4624** — Успешный вход (Logon Type 3 — сетевой).
- **4625** — Неудачный вход (Logon Type 3).
- **4648** — Вход с явным указанием учётных данных.
- **5140** — Доступ к общей папке.
- **5145** — Попытка доступа к общему ресурсу (с деталями по файлам/папкам).
- **4741** — Создание компьютерной учётной записи в AD.
- **4742** — Изменение компьютерной учётной записи.
- **4723** — Попытка смены пароля учётной записи.
- **4724** — Сброс пароля учётной записи.
- **2886/2887/2889** (Directory Services) — LDAP Bind без подписи или без канала.

## 2. Что важно коррелировать
- NTLM-аутентикации с рабочих станций к критичным серверам, где обычно используется Kerberos.
- Логины админских учёток на нетипичные хосты (особенно рабочие станции).
- Доступ к административным шарам (`C$`, `ADMIN$`) с неожиданных IP.
- Создание/изменение компьютерных учёток вне запланированных изменений.
- Смена паролей пользователей без заявок/запланированных работ.

## 3. Сетевые признаки
- LLMNR/NBT-NS-запросы к несуществующим именам.
- Запросы WPAD и автоконфигурации прокси.
- DHCP-ответы от неавторизованных серверов (DHCP Snooping violations).
- SMB/LDAP без подписи.

## 4. Рекомендации по настройке правил в SIEM
- Правило на **NTLM Logon Type 3** → фильтровать по источникам, где это не должно происходить.
- Правило на **доступ к ADMIN$** с клиентских VLAN.
- Правило на **создание/изменение компьютерных учёток** вне Change Window.
- Правило на **LDAP Bind без подписи** (события 2886, 2887, 2889).
- Правило на **частые запросы LLMNR/NBT-NS**.

## 5. Источники логов
- Windows Security Log (DC, серверы, рабочие станции).
- Directory Services Log (DC).
- DHCP Server Log.
- DNS Server Log.
- Network IDS/IPS (анализ SMB/LDAP).
