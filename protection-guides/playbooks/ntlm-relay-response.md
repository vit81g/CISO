# Playbook — Реагирование на NTLM Relay

## 🎯 Цель
Быстро выявить, локализовать и устранить атаку NTLM Relay, минимизировав ущерб.

## 1. Обнаружение
- Срабатывание правила SIEM на:
  - Event ID 4624 (Logon Type 3) с необычного источника.
  - 4776 (NTLM) с нетипичных хостов.
  - 5140/5145 — доступ к `C$` или `ADMIN$` с клиентских VLAN.
- Логи IDS/IPS: SMB/LDAP без подписи.

## 2. Подтверждение
- Проверить в логах DC источник IP и хостнейм атакующего.
- Убедиться, что жертва не выполняла эти действия намеренно.

## 3. Локализация
- Изолировать хост атакующего (блокировка на L2/L3).
- При необходимости — изолировать жертву для предотвращения дальнейшей компрометации.
- Отключить LLMNR/NBT-NS в поражённом сегменте.

## 4. Устранение
- Включить SMB signing и LDAP signing на целевых системах.
- Ограничить доступ к административным шарам по ACL.
- Применить Restrict NTLM.

## 5. Восстановление
- Сбросить пароли/ключи для учёток, фигурирующих в атаке.
- Провести аудит групп и ACL в AD.

## 6. Постинцидентный анализ
- Обновить правила SIEM для более раннего детекта.
- Проверить сегментацию сети.
- Обучить пользователей и админов выявлять аномалии.
