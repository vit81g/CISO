# Playbook: Kerberoasting (gMSA)

## Обнаружение
- Event ID 4769 — выдача TGS сервисному аккаунту (особенно gMSA).
- Множественные запросы TGS от одного клиента за короткое время.
- Необычные SPN-запросы.

## Изоляция
- Ограничить доступ к сервисам, запрашивающим аномальные TGS.
- Заблокировать подозрительную учётную запись.

## Анализ
- Определить, какие SPN запрашивались и с каких хостов.
- Проверить хэш TGS на наличие взлома в публичных репозиториях/форуме.
- Сопоставить время запроса с активностью пользователя.

## Устранение
- Изменить пароли сервисных аккаунтов.
- Перевести сервисные учётки на gMSA с длинными паролями.
- Ограничить выдачу TGS по определённым SPN.

## Предотвращение повторного инцидента
- Мониторить Event ID 4769 на массовые запросы.
- Внедрить автоматическую ротацию паролей gMSA.
- Использовать сложные случайные пароли.

## MITRE ATT&CK
- **T1558.003** — Kerberoasting
