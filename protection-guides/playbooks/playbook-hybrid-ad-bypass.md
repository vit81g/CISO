# Playbook: Hybrid AD Authentication Bypass

## Обнаружение
- Логи доступа к ADSync DB (SQL Server).
- Входы в Entra ID без соответствующих входов в on-prem AD.
- Аномальные токены S2S без подписи.

## Изоляция
- Отключить синхронизацию Entra Connect до завершения расследования.
- Изолировать сервер ADSync.

## Анализ
- Проверить логи SQL Server на запросы к таблицам с паролями/хэшами.
- Сопоставить время входа в Entra ID с доступом к ADSync DB.
- Проверить подписи S2S токенов.

## Устранение
- Сменить все пароли синхронизированных учёток.
- Обновить ADSync до последней версии.
- Включить контроль целостности данных в ADSync.

## Предотвращение повторного инцидента
- Ограничить доступ к ADSync DB по списку доверенных хостов.
- Мониторить изменения в конфигурации Entra Connect.
- Разделить сети управления AD и ADSync.

## MITRE ATT&CK
- **T1556** — Modify Authentication Process
