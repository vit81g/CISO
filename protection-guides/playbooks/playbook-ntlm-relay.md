# Playbook: NTLM Relay (Updated for 2025)

## Обнаружение
- **SIEM:** События Event ID 4624 Type 3 (SMB/LDAP вход) от нетипичных IP-адресов.
- Логи ntlmrelayx / Responder (только в тестовой среде).
- Аномалии IPv6 конфигураций на клиентах (IPv6 Relay/MITM6).
- DNS-запросы к несуществующим именам (LLMNR Poisoning).

## Изоляция
- Немедленно блокировать IP источника подозрительных SMB/LDAP входов на сетевом экране.
- Изолировать целевой хост, на который происходил релей, для предотвращения дальнейших действий.

## Анализ
- Проверить журналы Windows Security Log (4624, 4625, 4672).
- Определить, использовались ли учетные данные с высокими привилегиями.
- Сопоставить время входа с сетевыми логами (DHCP, DNS, RA/DHCPv6).

## Устранение
- Включить SMB signing на целевых системах.
- Настроить LDAP signing и channel binding.
- Отключить LLMNR/NBT-NS и WPAD в сети.
- Ограничить доступ к критическим сервисам только с доверенных сегментов.

## Предотвращение повторного инцидента
- Развернуть RA Guard/DHCP Snooping/DHCPv6 Guard на коммутаторах.
- Мониторить попытки NTLM входа на чувствительные сервисы.
- Обновить политики аутентификации: запрет NTLM, переход на Kerberos.

## MITRE ATT&CK
- **T1021.002** — SMB/Windows Admin Shares
- **T1557.001** — LLMNR/NBT-NS Poisoning
- **T1557** — Adversary-in-the-Middle
