# Playbook: AD Trusts Abuse

## Обнаружение
- Event ID 4765/4766 — изменение SIDHistory.
- Event ID 4769 — TGS-запросы для междоменных SPN.
- Входы trust-аккаунтов с неожиданных IP.

## Изоляция
- Ограничить доступ к доверенным доменам.
- Заблокировать подозрительные trust-аккаунты.

## Анализ
- Проверить изменения в SIDHistory и время их внесения.
- Сопоставить междоменные Kerberos запросы с реальной необходимостью.
- Определить источник атаки.

## Устранение
- Удалить несанкционированные SIDHistory.
- Перенастроить trust-отношения.
- Запретить делегацию для междоменных учёток.

## Предотвращение повторного инцидента
- Включить аудит изменений trust-объектов.
- Ограничить список админов, имеющих доступ к trust-настройкам.
- Регулярно проверять целостность trust-объектов.

## MITRE ATT&CK
- **T1134.005** — SID-History Injection
