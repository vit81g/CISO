# Глава 1. Сводка (Executive Summary)

Kimsuky — северокорейская APT-группа, также известная как **Thallium**, **Velvet Chollima**, **Black Banshee**.  
Действует как минимум с **2012 года** и занимается кибершпионажем, ориентированным на внешнюю политику и безопасность.

Группа применяет:
- spearphishing,
- социальную инженерию,
- вредоносные документы,
- watering hole-атаки.

Основные цели:  
**США, Южная Корея, Япония**, а также исследовательские центры, аналитические структуры, журналисты, эксперты по ядерной политике, институты внешней политики.

# Глава 2. Технические детали (Technical Details)

## Initial Access (Начальный доступ)
Kimsuky использует spearphishing, вредоносные документы, веб-хостинг, компрометированные домены, подготовительные письма и поддельные email-аккаунты журналистов.  
Основная техника: **Spearphishing Attachment (T1566.001)**.

## Execution (Исполнение)
BabyShark и PowerShell выполняются через **mshta.exe**, HTA-файлы, VBS-скрипты.  
Обеспечивается устойчивость через Run Keys.

## Persistence (Устойчивость)
Злоумышленники используют:
- вредоносные расширения браузеров,
- изменение file associations,
- RDP,
- модификацию автозагрузки,
- сервисы,
- вставки в реестр.

## Privilege Escalation (Повышение привилегий)
Используются:
- Win7Elevate (Metasploit),
- внедрение DLL,
- создание новых служб,
- обход UAC.

## Defense Evasion (Обход защит)
Применяются:
- отключение Windows Firewall,
- удаление логов,
- использование mshta.exe,
- скрытые загрузчики,
- механизм GREASE.

## Credential Access (Получение учётных данных)
Используются:
- ProcDump,
- кейлоггеры,
- Chrome-расширения,
- Nirsoft SniffPass,
- PHProxy-модификации.

## Discovery (Разведка)
Сбор системной информации, данных файловой системы, сетевых конфигураций.

## Collection (Сбор данных)
Кража документов HWP, кейлоггинг, macOS Python-имплант.

## Command and Control (Управление и контроль)
Используется модифицированный **TeamViewer 5.0.9104**.

## Exfiltration (Эксфильтрация)
Данные отправляются по email или через RC4/RSA-шифрование.

# Глава 3. Меры по снижению рисков (Mitigations)

Рекомендации CISA/FBI/CNMF:
- обучение пользователей,
- защита от spearphishing,
- MFA,
- запрет непроверенных расширений,
- мониторинг PowerShell / HTA / mshta.exe,
- контроль RDP,
- фильтрация email,
- защита от автоматических email forwarding rules.

Дополнительно:
- принцип наименьших привилегий,
- резервное копирование,
- управление уязвимостями,
- защита конечных точек (EDR/AV).

# Глава 4. Индикаторы компрометации (IOC)

Kimsuky использует домены, IP-адреса, email и хэши, перечисленные в Таблице 1.

Категории IOC:
- **Домены** (фишинг, C2, хостинг скриптов),
- **IP-адреса** (C2, промежуточные узлы),
- **Хэши** (BabyShark, кейлоггеры, Chrome-расширения),
- **Email-адреса операторов**,
- **Инфраструктура watering hole**.

IOC будут структурированы в приложениях A–K.
