# Инструкция по работе с Kaspersky Security Center (KSC)

## 1. Структура KSC

### 1.1. Стационарные ПК по площадкам

| Площадка | Доступ имеют |
|---------|---------------|
| CPLUS | группа mpspGU-IT-Техподдержка |
| CTSP | Вахтин М.С., Хохлов В.В., Федотов М.Ю. |
| MPSP | TAM-IT-AVR-admins, mpspGU-IT-Техподдержка |
| TAM | TAM-IT-AVR-admins, mpspGU-IT-Техподдержка |
| TMTP | Яшин А.А. |
| UPK | Серебрянов А.В., Шевелев Д.В. |

### 1.2. Ноутбуки
Выделены в отдельную группу Laptops CloseUSB, с разделением по площадкам.

### 1.3. Группы исключений

#### Исключения TLS 1.0
- ПК, которым требуется TLS 1.0.
- Доступ имеют все сотрудники, подключающиеся к KSC.

#### Временный доступ к USB
- Для ПК, которым временно требуется USB.
- Время нахождения: не более 12 часов.
- Доступ имеют все сотрудники, подключающиеся к KSC.

#### Временный доступ к USB / Руководство
- ПК руководителей, для которых согласованы исключения.

## 2. Создание пользовательского инсталляционного пакета

1. Сервер администрирования → **Дополнительно** → **Удаленная установка** → **Инсталляционные пакеты**  
2. Нажать: **Создать инсталляционный пакет**  
3. Выбрать: **Создать инсталляционный пакет для указанного исполняемого файла**  
4. Указать имя пакета  
5. Нажать «Обзор» → выбрать MSI/EXE/MSP/BAT/CMD  
6. (Опционально) Указать параметры для тихой установки  
7. Подтвердить создание

---

## 3. Запуск задачи установки ПО

1. Сервер администрирования → **Задачи** → **Новая задача**  
2. Тип: **Удаленная установка приложения**  
3. Источник: **Развернуть пакет Kaspersky Security Center**  
4. Выбрать пакет  
5. Настройки оставить по умолчанию  
6. Выбрать устройства  
7. Учётная запись: «Учётная запись не требуется»  
8. Указать расписание  
9. Задать имя задачи  
10. Запустить и контролировать выполнение

---

## 4. Требования к содержанию KSC
- Удалять неиспользуемые пакеты  
- Удалять выполненные задачи  

---

## 5. Установка KES и Агента Администрирования

Актуальный дистрибутив:

```
\\SPB-KSC01\KLSHARE\PkgInst\NetAgent_15.4.0.8873_KES_12.10.0.466\installer.exe
```

После установки ПК автоматически появляется в **Управляемые устройства**.

## 6. Выбор устройств при создании задач

### 6.1. Один ПК
Устройства → **Добавить** → Выбрать устройство

### 6.2. Выбор по файлу
Устройства → **Импорт** (TXT/CSV)

### 6.3. Выбор по группам
Можно выбирать площадки, исключения, ноутбуки
