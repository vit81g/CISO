
# Финальный README — Перевод и структурирование отчёта FireEye по APT41

Данный репозиторий содержит полный перевод отчёта FireEye об APT41 на русский язык, включая все главы, приложения, аналитические материалы и полную матрицу IOC.  
Все данные основаны **исключительно** на фактическом содержимом оригинального отчёта.  

---

## 📌 Содержание репозитория

### 1. Основной файл отчёта  
**`apt41_ru.md`** — полный перевод отчёта FireEye:

- Глава 1 — Executive Summary

## 📌 Приложения (IOC и технические материалы)

### A — Инфраструктура C2  
- A.1 — Базовая таблица доменов  
- A.2 — Расширенная таблица доменов  
- A.3 — IP-адреса и подсети C2

### B — Supply-chain IOC  
Атаки на ASUS, игровые студии, сервисы обновления.

### C — Malware Families Mapping  
Связь вредоносов: **SOGU, HIGHNOON, CRACKSHOT, POISONPLUG** и др.

### D — MITRE ATT&CK Mapping  
Полная таксономия техник APT41 в формате MITRE ATT&CK.

### E — Operational Timeline  
Хронология операций APT41 с 2012 по 2019 год.

### F — Hash IOC  
MD5, SHA1 и SHA256 всех обнаруженных бинарников.

### G — Email IOC  
Адреса операторов, включая привязку к контексту.

### H — Объединённая таблица C2  
Домены + IP + email инфраструктуры APT41.

### I — Игровые кампании  
IOC, домены, хэши и кампании против игровой индустрии.

### K — Финальная матрица IOC  
**master-матрица**, объединяющая:
- домены  
- IP  
- email  
- хэши  
- malware families  
- игровые цели
