# Учебный репозиторий: Практика по информационной безопасности

Этот репозиторий содержит структуру и материалы для трёхнедельной практики студентов колледжа по направлению "Информационная безопасность / Кибербезопасность".  
Материалы разделены по веткам и каталогам для удобства работы преподавателей и студентов.

---

## 📁 Структура репозитория

```
students_practic/
├── program/         # Расписание практики
│   ├── daily_schedule.md
│   └── daily_schedule.docx
├── report/          # Шаблоны отчётов
│   ├── lab_report_template.md
│   └── lab_report_template.docx
├── teory/           # Теоретические материалы
│   └── teory.md
├── test/            # Контрольные тесты по дням
│   ├── day01_quiz.md
│   ├── day02_quiz.md
│   ├── ...
│   ├── day15_quiz.md
│   └── tests_day01-15.zip
├── work/            # Практические задания
│   └── task_days.md
```

---

## 📌 Описание каталогов

### 📂 program/
План-график практики на 15 дней:
- `daily_schedule.md` — в Markdown формате
- `daily_schedule.docx` — печатная версия для преподавателя

### 📂 report/
Шаблоны отчётов, которые студенты заполняют ежедневно:
- `.md` — для работы в GitHub
- `.docx` — для печати и ручного заполнения

### 📂 teory/
Конспекты для самостоятельного изучения:
- `teory.md` — включает ключевые понятия и модели, охватывает все 15 дней

### 📂 test/
Контрольные тесты (без ответов):
- `dayXX_quiz.md` — 5 вопросов на день
- `tests_day01-15.zip` — архив со всеми тестами

### 📂 work/
Практические задания:
- `task_days.md` — список лабораторных работ, включая ссылки на pcap, команды и условия

---

## 🧭 Использование

1. Преподаватель клонирует репозиторий и создаёт ветки:
   - `main` (только README)
   - `teory`, `test`, `work`, `report`, `program`
2. Студенты читают `README.md`, переключаются на нужную ветку и работают с материалами.
3. Задания выполняются в Kali Linux, отчёты хранятся в `report/`, тесты — в `test/`.
